## Reglas del proyecto
- Trabaja siempre en una rama, nunca directamente en main.
- Antes de cada commit, ejecuta npm run lint y npm run build.
- No añadas dependencias sin avisarme.
- Explica qué cambias y por qué, en español.
- Los textos de la web viven en content/, no dentro de los componentes.
